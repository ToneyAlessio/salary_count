# 文档说明

这个仓库的 md 分三档，别混着看。

| 文件 | 写什么 | 什么时候翻 |
| --- | --- | --- |
| `README.md`（仓库根） | 项目是啥、目录、怎么导入跑起来 | 第一次 clone 或给别人介绍 |
| `main/README.md` | 工程层：页面、数据流、读代码入口 | 已打开 `main/`，要开始改代码 |
| `main/代码阅读指南.md` | 零基础顺文件：四件套、存储键、`salary.js` 阅读顺序 | 跟页面和组件对照看 |
| `开发日志.md` | 按日期记：定稿、实现、验证、已知问题 | 对不上行为或要追版本时 |
| `规划日志.md` | 未立项想法（多端、摸鱼等） | 确认「还没做」别当功能用 |

**开发日志**记事实；**规划日志**记可能。立项以后，把结论挪进开发日志，规划里留一行时间线就行。
